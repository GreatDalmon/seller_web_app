# SellerOps 🛒

A lightweight, robust Django web application built to streamline daily store operations. SellerOps provides a centralized dashboard to manage inventory stock, record sales, and track outstanding debts. Designed with Progressive Web App (PWA) support, it offers a resilient, app-like experience even on unstable networks.

## ✨ Features

*   **Sales Tracking:** Quickly add and log daily sales via an intuitive interface.
*   **Stock Management:** Monitor inventory levels and update product stock in real-time.
*   **Debt Monitoring:** Keep a clear ledger of outstanding customer debts and payments.
*   **PWA Ready:** Installable on mobile devices with an offline fallback page for uninterrupted workflow.
*   **Serverless Deployment:** Pre-configured with `vercel.json` and build scripts for seamless hosting on Vercel.

## 🛠️ Tech Stack

*   **Backend:** Python 3, Django
*   **Database:** PostgreSQL (via `urllib` parsing) / SQLite (Local)
*   **Frontend:** HTML5, CSS, Django Templates
*   **Deployment:** Vercel (Serverless), Gunicorn
